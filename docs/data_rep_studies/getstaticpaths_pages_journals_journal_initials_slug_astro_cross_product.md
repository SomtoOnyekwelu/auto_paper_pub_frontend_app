# Data Representation Study — `getStaticPaths()` (Phase 3: Cross-product Analysis)

Function path: `src/pages/journals/[journal_initials]/[slug].astro` (the `getStaticPaths` export).
Purpose: enumerate the `(journal_initials, slug)` route params, one per paper.

## Phase 1 — Inputs

- `papers: CollectionEntry<'papers'>[]` from `await getCollection('papers')` (glob loader over `src/data/papers/{new,published}/*.json`).
- Each `p.data` is `Paper` (validated by `paperSchema` at load time — invalid = build halts).

## Phase 2 — Conceptual Mapping

- Every paper record maps to exactly one static HTML page at `/journals/[journal_initials]/[slug]/`.
- Referentially integrity: if `journal_initials` doesn't exist in `journals.json`, throw (calls `getJournal(initials)` defensively in the dev path; even if absent it's caught by `layouts` referencing themes).
- `(journal_initials, slug)` is intended-unique: the slug is paired with its paper_id by the backend (`<id>-<kw1>-<kw2>`); collisions would surface as a duplicate-param build error.

## Phase 3 — Cross-product enumeration

For each `paper`:

- CP1 (valid): `params = { journal_initials, slug }`, `props = { paper }`. Page renders.
- CP2 (slug collides with existing static file at the same path): Astro build errors on duplicate routes.
- CP3 (journal_initials missing from journals.json): `getStaticPaths` could surface via `getJournal(paper.journal_initials)`; in current code the call happens inside the page body, so the page render fails at the per-paper pass.
- CP4 (empty papers collection): `getStaticPaths` returns `[]`; only the directory + archive routes exist.
- CP5 (paper has stale journal initials pointing to a journal later removed from `journals.json`): `getJournal` throws during page render → build halts.

## Phase 4 — Output Space

- Output: one Astro `getStaticPaths` return statement per paper → Astro generates one HTML file at `dist/journals/[initials]/[slug]/index.html` per entry.
- Side-channel: `props` flows into the page for prop-typed access (`Astro.props.paper`).
- Empty collection → no article pages; archive/directory routes still generated by their own `getStaticPaths`.

## Related chains

- The page body uses `highwire` and `fullAuthors` from the typed `paper` prop.
- Tier-4 E2E: `e2e_tests/e2e_1.0_article_landing_page.js` walks `dist/` to assert one HTML per expected paper.
- Tier-3 / Vitest: the schema itself is covered in `tests/data-rep.test.ts`.

## Notes / Decisive Decisions

- Decision: bake per-paper validation into the collection schema (`schema: paperSchema`). This is the Hand-Sanitizer for build-time Zero-Tolerance — malformed JSON halts the build at load, not at render.
- Decision: keep `getStaticPaths` thin; no schema check inside the function (would duplicate the collection-level validation).
