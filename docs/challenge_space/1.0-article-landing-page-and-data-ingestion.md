# Challenge: Article Landing Page & Data Ingestion

ID: 1.0 · Status: **Solved (MVP Standard) — Refined 2026-07-26** · Last Updated: 2026-07-26

## The Core Problem
Serve a single published paper to humans AND the Google Scholar crawler from one static HTML page: consume the backend's structured JSON + pre-calculated Highwire tags, validate them at build time, render with NIH/PubMed readability, inject exhaustive Highwire meta tags into `<head>` (not body — Issue 1), use an absolute `citation_pdf_url` (Issue 2), and emit human-readable HTML (Issue 3). Link the PDF galley through a local-looking URL the Edge Proxy resolves at the deploy host's edge — with zero client JS, zero runtime DB, and perfect crawler fidelity.

## Constraints & Boundaries
- Astro 7 (`output: 'static'`), zero client JS.
- Data: `src/data/journals.json` (array), `src/data/themes.json` (keyed object), `src/data/papers/{new,published}/<id>.json`.
- All incoming JSON validated by Zod at BUILD time — invalid file halts the build (Zero-Tolerance Tier 1 gate).
- Highwire tags exact: `citation_publication_date` as `YYYY/M/D` (NOT ISO); one `<meta>` per author / ORCID / institution; raw DOI (no `https://`); ORCID as full URL.
- Abstract MUST be visible in `<body>` (not behind a toggle).
- Visual fallback hierarchy: `<h1>` title > `<h3>` authors > `<small>` journal/issue.
- `citation_pdf_url` is rendered as an ABSOLUTE URL (domain derived at render time from `Astro.site.origin` — Issue 2 fix), but the path component is local-looking (Edge Proxy resolves it).
- `max-w-prose` serif abstract; Merriweather/Inter per journal, overridden from `themes.json` (Lora for grjaf/grjhpa).
- ≤ 7 plain-HTML `<a>` clicks from `/journals/` to the article.
- The frontend CONSUMES the backend's slug; it does NOT generate one.
- AMSSRN org logo (`/assets/logos/AMSSRN Logo 512  512.png`) renders in the page `<header>` on every Layout consumer; auto-resizes via `h-12 w-auto`. Per-journal `theme.logo_url` fields stay in `themes.json` contract and await per-journal SVGs from the brand owner.

## Living Implementation Plan

### Strategy Overview
Build the data-ingestion + contract layer first (the failure surface everything else rides on), then the article route, then the shared Layout/SeoHead. Validate every JSON at build time via Zod so a malformed paper halts the build naming the field — that is the Zero-Tolerance Tier 1 gate the teachings demand. Render with semantic HTML and Tailwind utilities that read per-journal CSS variables, so multi-tenant theming is a data problem, not a code problem.

### Data Flow
- **Input:** `journals.json` (array), `themes.json` (keyed object), `papers/{new,published}/<id>.json`.
- **Transform:** Zod-validate at build → `papers` Content Collection + validated journals/themes modules → `getStaticPaths` over papers (strict `parse` + referential-integrity check) → Layout injects the paper's journal theme CSS vars into `<head>` AND receives `<SeoHead slot="head">` (one `<meta>` per Highwire field) → body renders title / authors / abstract / PDF link with the visual hierarchy and the AMSSRN org-logo header.
- **Output:** one static HTML file per paper at `/journals/[initials]/[slug]/index.html` with exhaustive Highwire `<head>` meta, visible abstract + PDF download `<a>`, and human-readable multi-line indentation.

### Dependencies
- Upstream: backend JSON output (samples stand in for MVP).
- Downstream: 1.1 (archive links to the article) and 1.2 (sitemap lists the article; Edge Proxy serves the PDF).

### Phase 1 — Formal Input Breakdown & Concretization

`paper JSON`:
- P1 valid → `papers/new/8492.json` (brief's exact values).
- P2 missing `title` → copy of 8492, `title` removed.
- P3 ISO date → `citation_publication_date: "2026-07-20"`.
- P4 https DOI → `"https://doi.org/10.1234/grjbm.v6i2.102"`.
- P5 bare ORCID → `"0000-0002-1825-0097"`.
- P6 non-parallel author arrays → `authors` length 2, `citation_author_orcid` length 1.
- P7 unknown journal → `journal_initials: "xxxx"`.
- P8 title-based slug → `"effect-of-monetary-policy-on-financial-services"`.
- P9 empty authors → `authors: []`.
- P10 external pdf url → `"https://supabase.host/galley.pdf"`.

### Phase 2 — Conceptual Mapping (domain insights)
- Slug shape: `^[0-9]+(-[a-z0-9][a-z0-9-]*)?$` — numeric id with optional kebab body that may contain inner hyphens (real multi-word keywords like `social-progress` do). Accepts `8492-monetary-policy-finance` and `1045-fiscal-policy-social-progress`; rejects title-based slugs lacking the numeric id.
- DOI raw-prefix is lowercase-accepting (corpus bug corrected — Part 3 §7).
- ORCID full-URL required.
- `citation_author` / `citation_author_orcid` / `citation_author_institution` must be parallel (one entry per author).
- `authors[]` length must equal `citation_author[]` length.
- `journal_initials` must exist in `journals.json` (referential integrity — checked in `getStaticPaths`).

### Phase 3 — Cross-Product (intended behavior)
- CP1 (P1) → parse OK, page rendered.
- CP2 (P2) → Zod throws naming `title`; build halts.
- CP3 (P3) → throws naming `citation_publication_date` (must be YYYY/M/D).
- CP4 (P4) → throws naming `citation_doi` (raw prefix only).
- CP5 (P5) → throws naming ORCID.
- CP6 (P6) → throws naming the parallel-array invariant.
- CP7 (P7) → `getStaticPaths` throws `Unknown journal initials` (referential integrity).
- CP8 (P8) → throws naming `slug`.
- CP9 (P9) → throws (min 1 author).
- CP10 (P10) → throws naming `citation_pdf_url` (must be local-looking).

### Phase 4 — Output Space
Either (a) a parsed `Paper` (success → page rendered) or (b) a thrown ZodError (build halts, message printed). No silent leniency.

### Exact Format Specifications
- DOI: `^10\.\d{4,9}/[-._;()/:A-Za-z0-9]+$` · Valid `10.1234/grjbm.v6i2.102` · Invalid `https://doi.org/10.1234/grjbm.v6i2.102`
- ORCID: `^https://orcid\.org/\d{4}-\d{4}-\d{4}-\d{3}[\dX]$` · Valid `https://orcid.org/0000-0002-1825-0097` · Invalid `0000-0002-1825-0097`
- ISSN: `^\d{4}-\d{3}[\dX]$` · Valid `2811-1745`
- Publication date: `^\d{4}/\d{1,2}/\d{1,2}$` · Valid `2026/7/20` · Invalid `2026-07-20`
- Slug: `^[0-9]+(-[a-z0-9][a-z0-9-]*)?$` · Valid `8492-monetary-policy-finance`, `1045-fiscal-policy-social-progress` · Invalid `effect-of-monetary-policy-on-financial-services`
- citation_pdf_url (stored RELATIVE): `^/journals/[a-z]+/[0-9a-z-]+/galley\.pdf$` · Valid `/journals/grjbm/8492-monetary-policy-finance/galley.pdf` · Render emits ABSOLUTE via `new URL(rel, Astro.site.origin).href`.
