# Challenge: Deployment, Edge Rewrites, Sitemap, robots

ID: 1.2 · Status: Resolved (Cloudflare Pages chosen via Vision Trigger) · Last Updated: 2026-07-26

## The Core Problem
Make the static site reachable by crawlers and serve PDF galleys without committing binaries to Git: generate a sitemap, allow crawlers, and silently proxy `/journals/[initials]/[slug]/galley.pdf` to Supabase storage.

## Constraints & Boundaries
- `@astrojs/sitemap` generates `sitemap-index.xml` from `site: 'https://amssrn.org'`.
- `robots.txt` allows all + points to the sitemap.
- Edge Rewrite is HOST-LEVEL config (Vercel/Cloudflare/Netlify), not application code — the frontend only renders the local-looking `citation_pdf_url`.
- Google Scholar requires the PDF URL to be in the same subdirectory as the HTML abstract; the Edge Proxy satisfies this.

## Inclusion Criteria
- `astro.config.mjs` sitemap integration + `site`.
- `public/robots.txt`.
- A documented Edge Rewrite rule for the PDF path.
- Deployment of the static build.

## Exclusion Criteria
- The actual upload of PDFs to Supabase (backend responsibility).

## History & Decisive Decisions
- **Edge Rewrite, not a route handler:** a static build cannot proxy a binary; the host-level rewrite is the Hand-Sanitizer (no runtime node, no streams code).
- **2026-07-26 — Vision Trigger Decided: Cloudflare Pages.** Justification captured from the product owner: unlimited free-tier bandwidth (Vercel caps at 100 GB/mo); Workers included free with no cold start (V8 isolates, not Lambda); 300+ CDN locations; `_redirects` is the simplest possible Edge Proxy for MVP; future-road (R2 zero-egress galleys, Workers KV edge caches, Cloudflare Access on admin routes, D1 if ever needed) stays within one provider.

## Edge Rewrite — committed `_redirects` (Cloudflare Pages)

Pattern (shipped in `public/_redirects`):
```
/journals/:initials/:slug/galley.pdf  https://[your-supabase-project].supabase.co/storage/v1/object/public/galleys/:initials/:slug.pdf  200
```
`[your-supabase-project]` is replaced at deploy time with the actual Supabase project URL.

## Fallback
If the named-placeholder splat pattern cannot express nested segments at the Cloudflare Pages edge, a minimal Worker (~5 lines) is the documented fallback. Not built today — preferred path is `_redirects`.

## Verification (Tier 4 E2E)
`e2e_tests/e2e_1.2_cloudflare_redirect.js` asserts the `_redirects`, sitemap, and robots.txt artifacts. Run after every build; the script exits 1 on any failure.

## Current State
Resolved (Cloudflare Pages). Sitemap, robots.txt, and `_redirects` committed. Deploy itself awaits the host decision chain outside this repo.
