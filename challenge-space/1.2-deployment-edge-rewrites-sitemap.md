# Challenge: Deployment, Edge Rewrites, Sitemap, robots

ID: 1.2 · Status: Planned (configuration + docs; verifiable once a host is chosen) · Last Updated: 2026-07-26

## The Core Problem
Make the static site reachable by crawlers and serve PDF galleys without committing binaries to Git: generate a sitemap, allow crawlers, and silently proxy `/journals/[initials]/[slug]/galley.pdf` to Supabase storage.

## Constraints & Boundaries
- `@astrojs/sitemap` generates `sitemap-index.xml` from `site: 'https://amssrn.org'`.
- `robots.txt` allows all + points to the sitemap.
- Edge Rewrite is HOST-LEVEL config (Vercel/Cloudflare/Netlify), not application code — the frontend only renders the local-looking `citation_pdf_url`.
- Google Scholar requires the PDF URL to be in the same subdirectory as the HTML abstract; the Edge Proxy satisfies this.

## Inclusion Criteria
- `astro.config.mjs` sitemap integration + `site`.
- `public/robots.txt`.
- A documented Edge Rewrite rule for the PDF path.
- Deployment of the static build.

## Exclusion Criteria
- The actual upload of PDFs to Supabase (backend responsibility).

## History & Decisive Decisions
- **Edge Rewrite, not a route handler:** a static build cannot proxy a binary; the host-level rewrite is the Hand-Sanitizer (no runtime node, no streams code). Concrete example committed below for Vercel and Cloudflare Pages; the product owner picks the host at deploy time.

## Edge Rewrite (reference config)

Vercel (`vercel.json`):
```json
{
  "rewrites": [
    { "source": "/journals/:initials/:slug/galley.pdf",
      "destination": "https://<supabase-project>.supabase.co/storage/v1/object/public/:initials/:slug.pdf" }
  ]
}
```

Cloudflare Pages (`_redirects`):
```
/journals/:initials/:slug/galley.pdf  https://<supabase-project>.supabase.co/storage/v1/object/public/:initials/:slug.pdf  200
```

## Current State
Planned. The host is not yet chosen; the rule above is the canonical pattern and is wired into this doc for the deploy step. Sitemap + robots are committed in 1.0's build pass (cheap, no reason to defer).
